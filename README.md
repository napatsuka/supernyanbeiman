# ネコ・コープ！

スマホ2台で遊ぶ、物理演算の協力アクションゲームです（スーパーバニーマン風）。
通信は WebRTC の P2P（PeerJS）で、サーバーはシグナリングにのみ使います。

## あそびかた
- 黒猫（1P）と茶トラ（2P）で、ゴールのおさかな🐟を目指します（全6ステージ）
- ◀ ▶ 移動 / ジャンプ / つかむ（押しっぱなし）
- 相棒・箱・ロープ・黄色いペグをつかめます。ペグをつかんだままジャンプで大ジャンプ、ロープからは横っ飛び（ロープは少しずつずり落ちるので、下の方で大きく揺らせます）
- 高い壁は相棒を踏み台にしたり、上から相棒をつかんで引っぱり上げたりして越えます

## 起動方法
静的ファイルだけで動きます。

```bash
python -m http.server 8765 --bind 0.0.0.0
```

1. PCとスマホを同じWi-Fiにつなぐ
2. スマホ①で `http://<PCのIPアドレス>:8765/` を開いて「ルームを作る」
3. スマホ②で QR を読み取るか、4文字のコードを入力して「参加する」

> `localhost` で開いたホスト画面の QR はスマホから開けません。PCのIPアドレスで開いてください。

### おすすめ：HTTPS で公開
GitHub Pages / Netlify / Cloudflare Pages などにフォルダごと置くと、
別々のネットワーク（Wi-Fiと4G等）からでも遊べ、全画面・画面スリープ防止も有効になります。

## 仕組み
- ホスト（ルームを作った側）が Matter.js で物理演算を行い、30Hz で状態を送信
- 参加側は入力だけを送信し、受け取った状態を補間して描画
- 1台で遊ぶ「この端末で2人プレイ」はキーボード（1P: A/D/W/S、2P: ←/→/↑/↓）

## ファイル構成
- `index.html` / `style.css` … 画面
- `js/levels.js` … ステージデータ（ここを編集するとステージを追加・変更できます）
- `js/sim.js` … 物理・ゲームルール
- `js/render.js` … 描画
- `js/net.js` … P2P 通信
- `js/input.js` / `js/audio.js` / `js/main.js` … 入力・効果音・全体制御
